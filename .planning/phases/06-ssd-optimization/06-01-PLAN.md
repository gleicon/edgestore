<objective>
Create a StorageBackend trait that abstracts all disk I/O in the edgestore crate. The default implementation uses standard POSIX pread/pwrite. The trait boundary lets Phase 6 swap in FDP-aware backends without touching compaction or segment logic.

1. `StorageBackend` trait: `read(path, offset, buf)`, `write(path, offset, data)`, `fsync(path)`
2. `DefaultStorageBackend`: uses `std::fs::File` with `seek` + `read`/`write`
3. Refactor `SegmentWriter` to accept `&dyn StorageBackend` instead of `File`
4. Refactor `SegmentReader` to accept `&dyn StorageBackend` instead of `File`
5. `Engine::open` creates a `DefaultStorageBackend` and passes it to SegmentStore
6. Compaction logic is completely untouched — it still calls the same SegmentWriter API

Output: edgestore/src/storage_backend.rs, updated segment.rs, updated lib.rs
</objective>

      ```rust
      pub trait StorageBackend: Send + Sync {
          /// Read `buf.len()` bytes from `path` at `offset`.
          /// Returns bytes actually read (may be < buf.len() at EOF).
          fn read(&self, path: &std::path::Path, offset: u64, buf: &mut [u8]) -> Result<usize, EdgestoreError>;

          /// Write `data` to `path` at `offset`.
          fn write(&self, path: &std::path::Path, offset: u64, data: &[u8]) -> Result<(), EdgestoreError>;

          /// Flush all pending writes for `path` to durable media.
          fn fsync(&self, path: &std::path::Path) -> Result<(), EdgestoreError>;
      }
      ```
    - `DefaultStorageBackend` struct: empty struct (stateless), implements StorageBackend using std::fs::OpenOptions + seek + read/write
    - `read`: open file read-only, seek to offset, read into buf
    - `write`: open file read-write (create if absent), seek to offset, write_all
    - `fsync`: open file, sync_all
    - All methods return EdgestoreError (wrap io::Error)
    - No async in the trait — sync only per AGENTS.md constraints
  </behavior>
