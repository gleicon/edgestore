<objective>
Add four public methods to `Engine` implementing the replication API required by REPL-06:

- `export_manifest` — serialize the live segment list for a remote peer to inspect
- `import_segment` — accept an incoming segment from a peer with LWW conflict resolution (REPL-05)
- `compare_merkle` — tell a peer which key-range buckets differ from their view
- `range_merkle_root` — expose local tree root so peers can open the comparison

`import_segment` is the key operation. It reads an incoming segment's records one by one, compares each against the local store by WAL `timestamp`, and only applies records where the incoming timestamp is strictly greater (LWW). This is correct per REPL-05: WAL record timestamp (unix nanoseconds wall clock) determines conflict winners.

All four methods stay sync and fit the single-writer contract: only `import_segment` takes `&mut self`.
</objective>
