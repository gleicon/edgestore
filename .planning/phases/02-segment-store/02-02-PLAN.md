    - `pub struct SegmentWriter { base_path: PathBuf, segment_id: SegmentId, config: EdgestoreConfig }`
    - `SegmentWriter::new(base_path: PathBuf, segment_id: SegmentId, config: EdgestoreConfig) -> Self`
    - `fn write_dat_and_index(entries: &[(Vec<u8>, MemEntry)]) -> Result<(u64, u64, Vec<(Vec<u8>, u64)>), EdgestoreError>`
      returns (compressed_bytes, uncompressed_bytes, sparse_index_entries)
      where sparse_index_entries is Vec<(key: Vec<u8>, block_offset: u64)>
    - Algorithm:
      1. Accumulate serialized entries into `current_block: Vec<u8>` until size >= 3900 bytes (leave headroom for ZSTD overhead)
      2. When block is full: ZSTD compress at level 1, pad to next 4 KiB boundary with zero bytes, write to .dat file
      3. Block header written before compressed payload: [SEGMENT_BLOCK_MAGIC:u32-le][compressed_len:u32-le] (8 bytes) then compressed_payload then zero padding
      4. Record a sparse index entry (first key of block, block_start_offset) every SPARSE_INDEX_STRIDE keys
      5. After all entries: flush final partial block (even if < 3900 bytes)
    - .dat file starts with format header: [magic:u32-le=0x45445347][version:u8=1][reserved:u8*3=0] (8 bytes)
    - Unit test: write 200 entries, verify .dat file exists, first 8 bytes = header magic+version
    - Unit test: write 200 entries, verify sparse index has ceil(200/SPARSE_INDEX_STRIDE) entries
  </behavior>

  <action>
  Add `SegmentWriter` struct and `new()` constructor to segment.rs.

  Add `fn write_dat_and_index(&self, entries: &[(Vec<u8>, MemEntry)]) -> Result<(u64, u64, Vec<(Vec<u8>, u64)>), EdgestoreError>` to SegmentWriter impl.

  Use `std::fs::File` and `std::io::Write`. Use `zstd::encode_all(data_slice, 1)` for ZSTD level-1 compression. Pad to 4 KiB: if `compressed.len() + 8 < SEGMENT_BLOCK_SIZE`, append `SEGMENT_BLOCK_SIZE - (compressed.len() + 8) % SEGMENT_BLOCK_SIZE` zero bytes, ensuring total block (header + compressed + padding) is a multiple of SEGMENT_BLOCK_SIZE.
