## What was done

Added doc comments to `Engine::get`, `Engine::range`, and `Engine::prefix` in `edgestore/src/engine.rs` documenting the TTL lazy-expiry contract: expired records remain visible until `compact_once` removes their cohort. Added an integration test that verifies this contract end-to-end: inserts a record with TTL=1, flushes to segment, waits 2 seconds for expiry, asserts value is still visible (lazy expiry), runs `compact_once`, then asserts the value is gone.

## Tests

- `test_ttl_lazy_expiry_visible_before_compaction` (edgestore/tests/integration_core.rs)
  - Inserts key with TTL=1s, flushes memtable to segment
  - Waits 2 seconds (TTL expires)
  - Asserts value still visible before compaction (lazy expiry contract)
  - Runs `compact_once`, asserts value is None after compaction removes the expired cohort
