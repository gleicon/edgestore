<task type="auto">
  <name>Task 2: Implement BM25 scoring</name>
  <files>edgestore/src/text/index.rs</files>

  <behavior>
    - BM25 formula:
      ```
      IDF = ln((N - n + 0.5) / (n + 0.5) + 1)
      score = IDF * (f * (k1 + 1)) / (f + k1 * (1 - b + b * (dl / avgdl)))
      ```
      where:
      - N = total_docs
      - n = number of docs containing term (doc_freq)
      - f = term_freq in doc
      - dl = doc_len
      - avgdl = average doc length
      - k1 = 1.2 (default)
      - b = 0.75 (default)
    - `bm25_score(total_docs, doc_freq, term_freq, doc_len, avg_doc_len, k1, b) -> f32`
    - Document-level scoring: for a query with multiple terms, sum BM25 scores per term
  </behavior>

  <action>
  Implement bm25_score and document scoring function.
  </action>
