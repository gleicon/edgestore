<objective>
Implement `FilesystemRemoteStore` — the single Phase 4 implementation of the `RemoteStore` trait defined in Plan 04-01.

This is NOT S3. `FilesystemRemoteStore` uses a local directory as a durable segment store, simulating S3 semantics with filesystem operations. This design choice (D04) lets us verify the RemoteStore interface and anti-entropy integration without AWS credentials or network I/O. Real S3 (`S3RemoteStore`) is a future phase deliverable.

The store is content-addressed: files named `{hash_hex}.seg` where hash_hex is the 64-character lowercase hex encoding of the 32-byte BLAKE3 hash. Filenames ARE the content addresses — listing the directory is equivalent to listing stored objects.

Integration with AntiEntropyLoop (D08): after a segment is successfully applied via `engine.import_segment`, the loop calls `remote_store.upload(hash, data)` to push the segment to the RemoteStore backend. This makes the RemoteStore a durable copy of every locally-applied segment. The `remote_store` field on `AntiEntropyLoop` is `Option<Arc<dyn RemoteStore>>` — if None, the upload step is skipped.

No new external dependencies. All I/O uses `std::fs`.

Purpose: Complete the durable storage layer. Plan 04-05 integration tests use `FilesystemRemoteStore` to verify upload-download round-trips and BLAKE3 integrity.

Output: edgestore-repl/src/filesystem_remote_store.rs, updated anti_entropy.rs and lib.rs
</objective>

      - `upload(&self, hash: &[u8; 32], data: &[u8]) -> Result<(), EdgestoreError>`:
        - If `seg_path` already exists, return Ok(()) immediately (idempotent — content-addressed)
        - Write `data` to `{seg_path}.tmp` via `std::fs::write`
        - Rename `.tmp` to final path via `std::fs::rename`
        - Map all io::Error to `EdgestoreError::ReplicationError`
      - `download(&self, hash: &[u8; 32]) -> Result<Vec<u8>, EdgestoreError>`:
        - `std::fs::read(self.seg_path(hash))`
        - If NotFound: `EdgestoreError::ReplicationError(format!("segment not found: {}", Self::hash_hex(hash)))`
        - Other io errors: `EdgestoreError::ReplicationError(e.to_string())`
      - `list(&self) -> Result<Vec<[u8; 32]>, EdgestoreError>`:
        - `std::fs::read_dir(&self.base_dir)` — map error to ReplicationError
        - Filter entries with `.seg` extension
        - For each filename stem (64 hex chars): parse back to [u8; 32]:
          - Collect 2-char chunks: `(0..32).map(|i| u8::from_str_radix(&stem[i*2..i*2+2], 16))`
          - Skip filenames that are not exactly 64 hex chars (silently — they are not our files)
        - Return Vec of successfully parsed hashes
      - `delete(&self, hash: &[u8; 32]) -> Result<(), EdgestoreError>`:
        - `std::fs::remove_file(self.seg_path(hash))`
        - If NotFound: return Ok(()) (idempotent)
        - Other errors: ReplicationError
