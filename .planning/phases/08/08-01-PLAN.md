# Plan 08-01: API Polish and Code Quality

## Objective

Audit and polish all public APIs for v1.0 release. Ensure all public items have rustdoc comments, fix clippy warnings, audit visibility modifiers, and verify feature flags are correctly gated. Update all Cargo.toml files with proper metadata for crates.io publication.

**Purpose:** Production-ready API surface with comprehensive documentation and zero lint warnings.

**Output:** Clean API surface passing all quality gates.

## must_haves

- All public items in `edgestore` crate have rustdoc comments
- `cargo clippy --workspace -D warnings` passes with zero errors
- All workspace Cargo.toml files have complete metadata (version, description, license, repository)
- No `pub` visibility that should be `pub(crate)`
- `#![warn(missing_docs)]` directive added to lib.rs
- Feature flags correctly gate optional dependencies

## Tasks

<task>
  <id>08-01-T1</id>
  <title>Add rustdoc coverage, visibility audit, and fix warnings</title>
  <action>
    Add `#![warn(missing_docs)]` to `edgestore/src/lib.rs`. Then run `cargo doc --workspace --no-deps` and fix every warning by adding rustdoc comments to all public items (modules, traits, structs, enums, functions, constants). Use `//!` for modules and `///` for items with `# Arguments` and `# Returns` where appropriate. Concurrently, audit all `pub` items via `grep -r "^pub " --include="*.rs"` in edgestore/src. Convert internal implementation details (segment builder internals, WAL record format details, compaction state machine internals) to `pub(crate)`. Keep user-facing API (Engine, Transaction, Config, errors, vector/search traits) as `pub`. Document the final public API surface in a comment at the top of lib.rs.
  </action>
