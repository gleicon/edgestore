## What was done

Added regression test `test_snapshot_get_highest_lsn_across_segments` to `edgestore/src/snapshot.rs`. The test writes the same encoded key (`ns::shared_key`) into two separate segments with differing LSNs (lsn=1 in segment 0, lsn=5 in segment 1), then creates a `Snapshot` over both segments in ascending order [0, 1] and descending order [1, 0]. Both cases assert that `Snapshot::get` returns `"new_value"` (the lsn=5 winner), proving the LWW ordering in `Snapshot::get` is correct regardless of the segment ID enumeration order.
