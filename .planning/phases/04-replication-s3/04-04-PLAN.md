<objective>
Add an S3 client to the `edgestore-repl` crate implementing the storage layout from REPL-04.

S3 path layout (all paths relative to `prefix/{bucket}/`):
- `segments/{hex_hash}.dat` — immutable segment data; keyed by content hash
- `hosts/{host_id}/manifests/latest.json` — current manifest for a host (replication mailbox)
- `wal/{host_id}/{lsn:016x}.log` — WAL archive for disaster recovery
- `snapshots/{host_id}/manifest.json` — snapshot manifest for point-in-time restore

Endpoint override via `EDGESTORE_S3_ENDPOINT_URL` env var enables localstack testing without mocking.

    - `pub struct S3Client`:
      - `bucket: String`
      - `region: String`
      - `prefix: String` — path prefix within bucket (default empty string)
      - `endpoint_url: String` — base URL; default `https://s3.{region}.amazonaws.com`; overridden by `EDGESTORE_S3_ENDPOINT_URL`
      - `access_key: String`
      - `secret_key: String`

    - `S3Client::from_env() -> Result<Self, EdgestoreError>`:
      - Reads env vars: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_DEFAULT_REGION`, `EDGESTORE_S3_BUCKET`
      - Optional: `EDGESTORE_S3_PREFIX` (default ""), `EDGESTORE_S3_ENDPOINT_URL`
      - Missing required vars → `EdgestoreError::ReplicationError("missing env var: {name}")`

    - `fn sign_v4(method: &str, host: &str, path: &str, region: &str, body: &[u8], access_key: &str, secret_key: &str) -> Vec<(String, String)>`:
      - Returns Vec of (header-name, header-value) to add to the ureq request
      - Headers: `x-amz-date`, `x-amz-content-sha256`, `authorization`
      - Algorithm: AWS4-HMAC-SHA256
      - Date format: `YYYYMMDD` for credential scope, `YYYYMMDDTHHmmssZ` for x-amz-date
      - Use `sha2::Sha256` for body hash and HMAC intermediate steps
      - Use `hmac::Hmac<sha2::Sha256>` and `hmac::Mac` trait for HMAC computations
      - Signing key derivation: DateKey → DateRegionKey → DateRegionServiceKey → SigningKey (all HMAC-SHA256)
      - Service name: "s3"

    - Helper `fn s3_key(&self, path: &str) -> String`:
      - Returns `/{bucket}/{prefix}/{path}` or `/{bucket}/{path}` if prefix empty

    - Helper `fn s3_url(&self, path: &str) -> String`:
      - Returns `{endpoint_url}/{bucket}/{prefix_path}` with correct slash handling

    - `pub fn upload(&self, s3_path: &str, data: &[u8], content_type: &str) -> Result<(), EdgestoreError>`:
      - Compute x-amz-content-sha256 as hex of SHA256(body)
      - Call sign_v4 to get auth headers
      - ureq::put(&url).set headers.send_bytes(data) → 200/204 OK, else ReplicationError
      - Map HTTP errors and ureq errors to ReplicationError

    - `pub fn download(&self, s3_path: &str) -> Result<Vec<u8>, EdgestoreError>`:
      - sign_v4 for GET with empty body
      - ureq::get(&url).set headers.call() → read body bytes
      - 404 → ReplicationError("segment not found: {path}")
      - Other HTTP errors → ReplicationError

    - Public convenience methods all delegate to upload/download with the correct path:
      - `upload_segment(hash: &[u8; 32], data: &[u8])` → `upload("segments/{hex}.dat", data, "application/octet-stream")`
      - `download_segment(hash: &[u8; 32])` → `download("segments/{hex}.dat")`
      - `upload_manifest(host_id: &str, data: &[u8])` → `upload("hosts/{host_id}/manifests/latest.json", data, "application/json")`
      - `download_manifest(host_id: &str)` → `download("hosts/{host_id}/manifests/latest.json")`
      - `upload_wal_segment(host_id: &str, lsn: u64, data: &[u8])` → `upload("wal/{host_id}/{lsn:016x}.log", data, "application/octet-stream")`
      - `upload_snapshot_manifest(host_id: &str, data: &[u8])` → `upload("snapshots/{host_id}/manifest.json", data, "application/json")`

    - Hex formatting helper: `fn hex_encode(bytes: &[u8]) -> String { hex::encode(bytes) }`
    - Use `std::time::SystemTime` for date generation; format using manual arithmetic (no chrono dep)
  </behavior>

  Canonical request = method + \n + canonical_uri + \n + canonical_querystring(\n) + canonical_headers + \n + signed_headers + \n + hex(sha256(body))

  For the date, use SystemTime to get unix timestamp and derive YYYYMMDD and YYYYMMDDTHHmmssZ strings via manual division.
