<objective>
Integrate HNSW index into Engine and vector_search. Implement build_vector_index, sidecar file persistence, staleness detection, and automatic fallback to flat scan.

1. `Engine::build_vector_index(ns)`: scan all vectors in `__vec__{ns}`, build HnswIndex, serialize to sidecar file
2. Sidecar file: `{db_path}/vector/{ns_slug}.hnsw` with segment-id hash in header
3. `vector_search` routing: check for sidecar → load if needed → check staleness → use HNSW or flat scan
4. Staleness: compute BLAKE3 hash of current segment IDs; compare to hash stored in sidecar header
5. Metrics: `vector_index_load_ms` and `vector_index_stale` in MetricsSnapshot
6. Lazy load: index is loaded on first search, not at Engine::open

Output: updated engine.rs, updated vector/search.rs, updated metrics.rs
</objective>

          }
