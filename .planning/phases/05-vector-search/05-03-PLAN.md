<objective>
Implement all three distance metrics (Cosine, L2, DotProduct) with SIMD acceleration and scalar fallback.

1. `Metric` enum with three variants.
2. `distance(query: &[u8], candidate: &[u8], dtype: Dtype, metric: Metric) -> f32` — the main API.
3. SIMD path: use `wide` crate `f32x8` for f32 dtype on x86_64 and aarch64. Stable Rust only.
4. Scalar fallback: always-correct scalar implementation for all dtypes (f32, f16, i8).
5. Parity: SIMD and scalar return identical results on same f32 data (within floating-point tolerance).
6. f16 support: decode to f32, compute, no native f16 SIMD (scalar widening).
7. i8 support: cast to f32, compute, no native i8 SIMD (scalar widening).

Output: edgestore/src/vector/distance.rs, updated Cargo.toml with `wide` dependency
</objective>

    - `distance_simd_f32(query: &[f32], candidate: &[f32], metric: Metric) -> f32`:
      - Uses `wide::f32x8` for 8-wide lanes
      - For cosine: accumulate dot product and norms in SIMD, then compute final formula scalar
      - For L2: accumulate squared differences in SIMD, then sqrt scalar
      - For dot product: accumulate dot product in SIMD, then negate scalar
      - Tail loop for remaining elements (< 8)
    - `distance(bytes_a: &[u8], bytes_b: &[u8], dtype: Dtype, metric: Metric) -> f32`:
      - The public API function
      - Decodes bytes_a and bytes_b to Vec<f32> based on dtype:
        - f32: direct transmute from bytes to &[f32]
        - f16: decode each pair of bytes to f32 (use `half` crate or manual: `f16::from_le_bytes` → `to_f32()`)
        - i8: cast each byte to f32
      - If dtype == F32: calls `distance_simd_f32` (SIMD path)
      - Else: calls `distance_scalar` (scalar path)
      - Panic (or error) if lengths mismatch after dtype decoding
    - No unsafe blocks allowed (project constraint per AGENTS.md — "Sync core" doesn't mention unsafe prohibition, but wide crate abstracts it)
  </behavior>
