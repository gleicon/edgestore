<objective>
Implement the compaction algorithm inside Compactor. The core invariant: deathtime-cohort compaction
achieves zero live-data relocation for fully-expired cohorts. For partially-expired cohorts, only
surviving records are copied to a new output segment. Write budget prevents unbounded I/O per cycle.

This plan contains no Engine integration — that comes in Plan 03-04. Compactor operates on a
Manifest reference and a caller-supplied `now_nanos: i64` (enables deterministic testing without
wall-clock dependency).
</objective>

  <behavior>
    - `Compactor::compact_cycle(manifest: &mut Manifest, now_nanos: i64, pinned_segment_ids: &HashSet<SegmentId>) -> Result<CompactionStats, EdgestoreError>`:
      - Load `manifest.list_segments()`
      - Filter out any segment whose id is in `pinned_segment_ids`
      - Call `identify_cohorts(segments, now_nanos)` to get sorted cohort list
      - For each cohort (fully-expired first):
        - If `stats.bytes_written >= self.write_budget_bytes`: break (budget exhausted)
        - Skip if all segment_ids in the cohort are pinned
        - If `cohort.is_fully_expired`: call `collect_expired_cohort`
        - Else: call `compact_partial_cohort` with `next_segment_id` = highest existing + 1
      - Return stats
    - next_segment_id tracking: start from `manifest.list_segments().iter().map(|m| m.segment_id).max().unwrap_or(0) + 1`, increment after each new segment written

    - Unit test `test_compact_cycle_respects_budget`:
      - Create 3 expired cohorts (3 segments each = 9 segments total)
      - Set write_budget_bytes to 0 (force immediate budget exhaustion after first collection)
      - Call compact_cycle with now_nanos = far future
      - Assert: only the first cohort was processed (stats.cohorts_collected <= 1); remaining segments still exist
  </behavior>

  <action>
  Implement compact_cycle. The pinned_segment_ids parameter uses HashSet<SegmentId> — import `use std::collections::HashSet;`.
  For fully-expired cohort filtering: a cohort is fully-expired only if NONE of its segments are pinned.
  If some but not all segments in a cohort are pinned, skip that cohort entirely (conservative — don't partially compact a pinned cohort).

  For next_segment_id: compute once before the loop; increment after each write.
  </action>
