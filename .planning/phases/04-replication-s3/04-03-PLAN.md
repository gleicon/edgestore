<objective>
Create the `edgestore-repl` workspace crate providing the HTTP transport layer for replication.

This crate keeps the `edgestore` core sync and dependency-free. The HTTP client uses `ureq` (sync, no async runtime). The HTTP server uses `tiny_http` (sync, multi-threaded request handling). Both implement or serve the 6 endpoints from REPL-03: ListManifests, GetManifest, CompareMerkle, RequestDelta, SendSegments, Ack.

The server wraps `Arc<Mutex<Engine>>` — engine access is serialized, which is correct per the single-writer constraint. The server thread runs in the background; the application retains the Arc to continue using the Engine directly.

Wire format: JSON over HTTP/1.1. Segments are sent as binary in POST body with Content-Type: application/octet-stream. Manifest operations are JSON.
</objective>

    - `HttpReplicationServer::start(&self, bind_addr: &str) -> Result<std::thread::JoinHandle<()>, EdgestoreError>`:
      - Creates `tiny_http::Server::http(bind_addr)` — returns Err on bind failure
      - Clones the Arc<Mutex<Engine>>
      - Spawns `std::thread::spawn(move || { /* request loop */ })` and returns the JoinHandle
    - Request dispatch (inside server loop) — match on request method + URL:
      - `GET /manifests` → lock engine, call `export_manifest()`, respond with JSON list of "local" host_id
        - For v1, ListManifests returns a single-element list: `["local"]` (this node's own host ID)
        - Respond: 200 OK, Content-Type: application/json, body = `["local"]`
      - `GET /manifests/local` → lock engine, call `export_manifest()`, respond with manifest bytes
        - Respond: 200 OK, Content-Type: application/json, body = manifest JSON
      - `POST /merkle/compare` → read body (32 bytes = root), call `compare_merkle(root)`, respond with JSON array of bucket indices
      - `POST /delta` → read body as JSON KeyRange + since_lsn, call `request_delta` (returns DeltaManifest of segments in range after since_lsn), respond with JSON

      - `POST /segments` → body = 32-byte hash + raw .dat bytes; write to temp file; call `import_segment`
      - `POST /ack` → read body as JSON `{"lsn": u64}`; for v1, log and respond 200 (no persistent ack tracking yet; REPL-06 SC5 is tested via client-side tracking)
      - Unknown routes → 404
    - Errors from engine lock → respond 500 with error message body
    - Each request processed synchronously (tiny_http is multi-threaded but we serialize via Mutex)
