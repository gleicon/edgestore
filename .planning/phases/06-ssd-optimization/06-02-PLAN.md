<objective>
Implement FDP (Flexible Data Placement, NVMe 2.0) placement hints for segment writes. The StorageBackend trait from 06-01 gets an optional `write_with_hint` method. A mock backend verifies hint correctness without requiring real FDP-capable hardware.

1. Extend `StorageBackend` trait with `write_with_hint(path, offset, data, hint: PlacementHint)` — default impl delegates to `write`
2. `PlacementHint` struct: `cohort_bucket: i64` (maps to FDP placement handle)
3. `FdpStorageBackend`: wraps another StorageBackend, emits `fcntl(fd, F_SET_FILE_DATA_PLACEMENT_HINT, ...)` or platform-equivalent before writes
4. `MockFdpBackend`: records all `(path, offset, cohort_bucket)` calls for test verification
5. SegmentWriter: on flush, computes cohort_bucket from segment metadata and calls `write_with_hint`
6. All FDP code is behind `#[cfg(target_os = "linux")]` or equivalent guard

Output: edgestore/src/fdp_backend.rs, updated segment.rs, updated config.rs
</objective>
