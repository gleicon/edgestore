<objective>
Add vector_put, vector_get, and vector_delete methods to Engine. These are thin overlays on the existing KV API:

1. `vector_put(ns, key, dims, dtype, data)` → validates → encodes → `put(__vec__{ns}, key, encoded_bytes)`
2. `vector_get(ns, key)` → `get(__vec__{ns}, key)` → decodes → returns VectorRecord
3. `vector_delete(ns, key)` → `delete(__vec__{ns}, key)`

The KV layer sees only opaque bytes. The synthetic namespace `__vec__{ns}` (D09) ensures isolation from user KV data.

Output: edgestore/src/vector/api.rs, updated edgestore/src/vector/mod.rs, updated edgestore/src/engine.rs
</objective>
