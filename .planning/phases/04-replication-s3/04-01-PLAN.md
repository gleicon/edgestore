<objective>
Create two new pure-Rust modules in the edgestore crate:

1. `merkle.rs` — Range-level Merkle tree over 16 key-range buckets. Each bucket covers one leading nibble of encoded key space (0x00–0x0F). A bucket's hash is BLAKE3 of all segment `merkle_root` values in that bucket (sorted by segment_id). The tree root is BLAKE3 of all 16 bucket hashes concatenated. Two nodes with identical data have identical roots; `differing_buckets` tells them which key ranges to sync.

2. `replication.rs` — Transport-agnostic replication protocol: types (HostId, KeyRange, SegmentRef, DeltaManifest) and the `ReplicationProtocol` trait. The trait is the contract between the core library and transport implementations (HTTP in Plan 04-03). No I/O here — types and trait only.

Both modules must compile clean with existing deps (blake3 already in Cargo.toml). No new external deps for this plan.
</objective>
