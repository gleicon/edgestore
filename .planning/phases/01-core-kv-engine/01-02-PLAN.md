  1. Attempt to read exactly 8 bytes (4 for crc32c + 4 for compressed_len). If fewer bytes available (EOF), break loop.
  2. Parse crc32c (u32-LE) and compressed_len (u32-LE).
  3. Attempt to read exactly compressed_len bytes. If fewer bytes available (partial write), break loop.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem→WalReader | WAL file bytes cross trust boundary on read — must be treated as untrusted |
| caller→WalWriter::append | Caller-supplied WalRecord values (sizes, op byte) cross into serialization |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | WAL record CRC32C | mitigate | CRC32C recomputed on every read; mismatch causes record skip with log; no silent acceptance |
| T-02-02 | Tampering | WAL file header magic/version | mitigate | WalReader::open validates magic bytes and version before reading any records; returns hard error on mismatch |
| T-02-03 | Denial of Service | compressed_len field in frame header | mitigate | Validate compressed_len against a reasonable max (e.g., 64 MB) before allocating read buffer; return CorruptRecord if exceeded |
| T-02-04 | Denial of Service | val_len integer overflow in deserialize_record | mitigate | Use checked arithmetic when computing total expected buffer length; return CorruptRecord on overflow |
| T-02-05 | Spoofing | Path traversal in WAL file path | mitigate | WAL path is always constructed by the engine as `config.path.join(format!("wal-{:016x}.log", lsn))`; never constructed from user input |
| T-02-06 | Information Disclosure | Value bytes in WAL | accept | At-rest encryption is out of scope for v1; document that WAL contains plaintext values |
| T-02-SC | Tampering | lz4_flex, crc32c crate installs | mitigate | Verify on crates.io before cargo add; check download counts and owner identity; block on [ASSUMED] packages |
</threat_model>
