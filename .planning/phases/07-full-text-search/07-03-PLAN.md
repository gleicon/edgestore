<objective>
Integrate the inverted index into the Engine. Implement TextEngine trait with index_text, search_text, and delete_text methods. The inverted index is stored in the KV layer under `__text__{ns}` synthetic namespace.

1. `TextEngine` trait: `index_text(ns, key, text, facets)`, `search_text(ns, query, k)`, `delete_text(ns, key)`
2. `text_namespace(ns)` helper: prepend `__text__` (like vector_namespace)
3. `Engine::index_text`: tokenize text, build/update InvertedIndex, serialize to KV
4. `Engine::search_text`: tokenize query, fetch posting lists per term, compute BM25, return top-k
5. `Engine::delete_text`: remove document from inverted index
6. Results: `Vec<TextSearchResult>` with `doc_id` and `score`

Output: edgestore/src/text/engine.rs, updated engine.rs
</objective>
