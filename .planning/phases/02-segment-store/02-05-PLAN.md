## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| memtable→flush_memtable | In-memory entries flushed to disk; key/value sizes unchecked before write |
| segment_store.get→Engine.get | Segment data returned to caller as if from memtable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Tampering | segment merge lsn ordering | mitigate | Highest lsn wins in range_scan merge; lsn is monotonic u64 from Engine's lsn_counter |
| T-02-05-02 | Denial of Service | auto-flush threshold | mitigate | Average entry size estimate is conservative (256 bytes); worst case flushes slightly early |
| T-02-05-03 | Information Disclosure | Delete tombstone leak | mitigate | Engine.get() checks op==Delete from segment and returns None; tombstone value never exposed |
</threat_model>
