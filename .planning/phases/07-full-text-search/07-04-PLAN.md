<objective>
Add faceting and typo tolerance to full-text search.

1. **Faceting**: Store facet values in postings, filter search results by facet criteria
   - FacetFilter struct: field → FacetValue constraint
   - filter_by_facets(postings, filters) → filtered postings
   - Engine::search_text_with_facets(ns, query, k, filters)

2. **Typo tolerance**: Levenshtein distance ≤ 1 for query terms
   - levenshtein(a, b) → usize (Wagner-Fischer for short strings)
   - TypoIndex: n-gram (n=2,3) → terms mapping for fast fuzzy lookup
   - During search: for each query term, also search terms with edit distance ≤ 1
   - Combine scores from exact + fuzzy matches

3. Both features integrate into existing search_text flow

Output: edgestore/src/text/facet.rs, edgestore/src/text/typo.rs, updated engine.rs
</objective>
