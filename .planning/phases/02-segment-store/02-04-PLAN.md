    - `pub struct Manifest { path: PathBuf, file: File, segments: Vec<SegmentMeta> }`
    - `Manifest::open(path: &Path) -> Result<Manifest, EdgestoreError>`
      - creates file if not exists; writes 8-byte header on creation
      - if file exists: validates 8-byte header (wrong magic → ManifestCorrupt; wrong version → ManifestCorrupt)
      - replays all framed entries: for each frame: read 8-byte header, validate CRC32C (mismatch → skip + warn); deserialize JSON; apply: Add → push to self.segments, Remove → remove from self.segments by segment_id
    - `pub fn add_segment(&mut self, meta: SegmentMeta) -> Result<(), EdgestoreError>`
      - appends ManifestEntry(Add, meta) as framed entry; calls file.sync_all(); updates self.segments
    - `pub fn remove_segments(&mut self, ids: &[SegmentId]) -> Result<(), EdgestoreError>`
      - for each id: appends ManifestEntry(Remove, id) as framed entry; calls file.sync_all() once after all appends; removes from self.segments
    - `pub fn list_segments(&self) -> &[SegmentMeta]` — returns self.segments slice
    - Unit test: Manifest::open on new path → empty segment list
    - Unit test: add_segment(meta1), add_segment(meta2), close file, Manifest::open again → list_segments returns both metas (replay correct)
    - Unit test: add_segment(meta1), remove_segments([meta1.segment_id]), reopen → list_segments empty
    - Unit test: corrupt last 4 bytes of manifest file, reopen → recovers prior segments (corrupt entry skipped)
  </behavior>

  <action>
  Add `Manifest` struct and all methods. Open file with `OpenOptions::new().create(true).read(true).write(true).append(false)` so we can both read (replay) and write (append). After replay, seek to end for subsequent appends.

  Replay loop: seek to byte 8 (after header), loop:
  1. Read 8 bytes (crc32c + entry_len). If fewer: break (EOF).
  2. Read entry_len bytes. If fewer: break (partial write).
  3. Recompute CRC32C over entry bytes. If mismatch: eprintln warning, continue.
  4. serde_json::from_slice → apply to segments list.

  For append: seek to end; write framed entry; sync_all().
