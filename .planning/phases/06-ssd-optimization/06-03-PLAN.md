<objective>
Implement the HNSW (Hierarchical Navigable Small World) graph data structure for approximate nearest neighbor search. This is the core index that replaces flat scan for large vector collections (>500K vectors per D12).

Key design decisions from D13:
- HNSW is stored in a sidecar file (not in segments)
- Lazy-loaded on first HNSW search
- Staleness detected by segment-id hash comparison
- No async, no unsafe

1. `HnswIndex<T>`: generic over distance metric
2. `HnswNode`: vector_id, vector_data (raw bytes), neighbors per layer
3. `search(query, k, ef)`: greedy beam search from entry point, layer by layer
4. `insert(vector_id, data, m, ef_construction)`: add node, probabilistically assign to layers, connect to nearest neighbors
5. `serialize/deserialize`: binary format for sidecar file storage
6. Uses the existing `distance()` function from Phase 5 for distance computation

Output: edgestore/src/vector/hnsw.rs
</objective>

  <behavior>
    - `search(query_data: &[u8], k: usize, ef: usize) -> Result<Vec<(Vec<u8>, f32)>, EdgestoreError>`:
      1. Decode query to VectorRecord (validate dims/dtype match index)
      2. Start at entry_point, search from top layer down to layer 0
      3. For each layer: greedy beam search
         - Maintain two sets: `candidates` (min-heap by distance) and `visited`
         - Start with entry point
         - Pop closest candidate, add its neighbors to candidates if not visited
         - Keep at most `ef` candidates
         - Stop when no closer candidate exists
      4. At layer 0: return top-k closest as results
    - Use `std::collections::BinaryHeap` with custom Ord (same pattern as flat scan search)
    - Distance computation uses existing `distance()` from Phase 5
    - `ef` parameter controls recall vs speed tradeoff (default = max(k, 50))
  </behavior>

<task type="auto">
  <name>Task 3: Implement probabilistic insertion</name>
  <files>edgestore/src/vector/hnsw.rs</files>

  <behavior>
    - `insert(vector_id: Vec<u8>, vector_data: Vec<u8>, rng: &mut impl Rng) -> Result<usize, EdgestoreError>`:
      1. Assign node to layers: `layer = floor(-ln(uniform(0,1)) * mL)` where `mL = 1.0 / ln(M as f64)`
      2. Add node to `nodes` vector, get its index
      3. If first node: set as entry_point, max_layer = node's layer
      4. For each layer from min(node.layer, max_layer) down to 0:
         - Find `M` nearest neighbors in that layer using search_layer (same greedy beam, ef=ef_construction)
         - Add bidirectional edges between new node and each neighbor
         - If neighbor already has M edges, prune farthest (keep closest M)
      5. If node.layer > max_layer: update entry_point and max_layer
    - `search_layer(query_idx, entry_points, ef, layer)`: greedy beam search restricted to one layer
    - Pruning: when a node has > M neighbors, remove the farthest neighbor(s)
  </behavior>
