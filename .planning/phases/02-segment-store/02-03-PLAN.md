  <behavior>
    - `pub fn get(&self, key: &[u8]) -> Result<Option<MemEntry>, EdgestoreError>`
    - Step 1: hash key to u64 (same BLAKE3 truncation as filter build); `if !self.filter.contains(&hash) { return Ok(None); }`
    - Step 2: open .idx file; read all entries; binary-search for largest key <= query key → get block_offset
      - if no index entry <= query key: start from first block (offset = 8, after file header)
    - Step 3: open .dat file; seek to block_offset; read block header (8 bytes); validate SEGMENT_BLOCK_MAGIC; read compressed_len bytes; ZSTD decompress (cap at 2 * SEGMENT_BLOCK_SIZE * 256 = 2 MB); scan entries for exact key match
    - Step 4: if not found in that block, continue to next block until key > max possible in remaining blocks or EOF
      — but typically only 1–2 blocks need scanning since sparse index stride = 64 and keys are sorted
    - Returns Ok(Some(entry)) for the latest version of key (highest lsn); Ok(None) if not found; Err on I/O or decompression failure
    - Unit test: flush 200 sorted entries → get(entries[100].key) returns the correct entry
    - Unit test: flush 200 sorted entries → get(b"not_present_key") returns Ok(None)  (xor filter rejects)
    - Unit test: get() on a key present in segment → xor filter does NOT return Ok(None) (no false negative)
  </behavior>

  <action>
  Add `get()` method to SegmentReader.

  Read .idx: open file, read u64-le count, read count entries of [key_len:u32-le][key_bytes][offset:u64-le]. Store as Vec<(Vec<u8>, u64)>. Binary search for largest index key <= query key.

  Read .dat block: seek to block_offset, read 8 bytes (magic + compressed_len), validate magic == SEGMENT_BLOCK_MAGIC (return SegmentCorrupt if wrong), read compressed_len bytes, zstd::decode_all with cap check.

  Scan decompressed block: loop calling deserialize_entry advancing pos; compare key field; if found: return Some(entry); if key > query key and entries are sorted: break.

  ZSTD cap: `if decompressed.len() > 2 * SEGMENT_BLOCK_SIZE * 256 { return Err(SegmentCorrupt("decompressed block too large".to_string())); }`

  Add 3 unit tests.
  </action>

  <behavior>
    - `pub fn range_scan(&self, start: &[u8], end: &[u8]) -> Result<Vec<(Vec<u8>, MemEntry)>, EdgestoreError>`
      returns all entries where key >= start && key <= end, sorted ascending
    - Algorithm:
      1. Load .idx entries; find largest index key <= start → seek to that block_offset (or first block if none)
      2. Scan blocks sequentially; for each entry in each block: if key >= start && key <= end: collect; if key > end: stop
    - Returns empty Vec if no entries in range

  </behavior>
