<objective>
Add five public methods to `Engine` implementing the replication API (REPL-06) and conflict resolution (REPL-05):

- `export_manifest` — returns local segment list as `Vec<SegmentRef>` for a remote peer to diff against
- `missing_segments` — pure set-diff: given peer's segments, returns hashes we do not have
- `import_segment` — accept raw segment bytes, verify BLAKE3, write atomically, apply LWW per record
- `range_merkle_root` — build and return the local RangeMerkleTree root (anti-entropy probe value)
- `compare_merkle` — returns true if local root == other root (caller decides whether to skip sync)

`import_segment` is the critical path. It takes raw segment bytes (not a path), verifies BLAKE3 matches the claimed hash, writes to a `.tmp` file, verifies, renames to final location, updates the manifest, then applies LWW record-by-record. This matches the D08 atomic-progress protocol used by the AntiEntropyLoop.

LWW rule (D06): incoming record wins if its WAL `timestamp` is strictly greater than the local record's timestamp. On timestamp collision, `HostId` lexicographic comparison breaks the tie: lower HostId string wins. NTP synchronization is a documented operational requirement.

`compare_merkle` returns `bool` (not a bucket-diff Vec). The simple true/false probe is sufficient: if false, the caller proceeds to manifest-diff via `export_manifest` + `missing_segments`. Fine-grained bucket routing is not used in Phase 4 (D02).

    - `pub fn import_segment(&mut self, data: &[u8], hash: &[u8; 32]) -> Result<ImportResult, EdgestoreError>`:
      - Step 1: Check if hash already in local manifest → return `Ok(ImportResult::Skipped)` immediately
      - Step 2: Verify BLAKE3(data) == hash → if not, return `Ok(ImportResult::HashMismatch)`
      - Step 3: Write data to `{segment_dir}/{hash_hex}.tmp` (use `format!("{:02x}", b)` iteration for hash_hex — no hex crate)

      - Step 6: For each record, apply LWW (D06):
        - Look up same encoded key in local memtable
        - Local entry exists AND `local.timestamp > incoming.timestamp` → skip (local wins)
        - Local entry exists AND `local.timestamp == incoming.timestamp`:
          - Compare `local.host_id` vs `incoming.host_id` lexicographically
          - Lower host_id wins → if local.host_id <= incoming.host_id → skip; else apply

      - Step 7: Update manifest to include the new segment
      - Return `Ok(ImportResult::Applied { keys_written, keys_skipped })`
