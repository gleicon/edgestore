<objective>
Implement the Snapshot type: a point-in-time read view that pins the segments it was created from
against compaction. When the Snapshot is dropped, pins are released.

The read API (get, range) reads directly from pinned segments on disk — no Engine lock needed.
This enables concurrent snapshot reads while compaction runs on other segments.

Plan 03-04 (Engine integration) wires Engine::snapshot() to create Snapshot instances.
</objective>
