<task type="auto">
  <name>Task 2: Implement tokenizer</name>
  <files>edgestore/src/text/tokenizer.rs</files>

  <behavior>
    - `fn tokenize(text: &str) -> Vec<Token>`:
      1. Split on any non-alphanumeric character (regex-like)
      2. Lowercase each token
      3. Filter out empty tokens and stopwords
      4. Apply simple stemming
      5. Return tokens with position index
    - Stopwords: static HashSet of ~30 words
    - Simple stemmer rules:
      - "ies" → "y" (e.g., "babies" → "baby")
      - "ies" not preceded by vowel → "y"  
      - "es" → "e" if ends with "ches", "shes", "sses", "xes", "zes", "oes"
      - "s" → "" if ends with non-s-sibilant
      - "ing" → "" if word > 4 chars
      - "ed" → "" if word > 3 chars
      - "ly" → "" if word > 4 chars
    - Token struct:
      ```rust
      #[derive(Debug, Clone, PartialEq)]
      pub struct Token {
          pub term: String,
          pub position: usize,
      }
      ```
    - TokenStream: iterator wrapper over Vec<Token>
  </behavior>
